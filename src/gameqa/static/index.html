Unity 日志扫描配置

扫描 Error/Exception/Fatal 行并统计；超出阈值即失败。由对应平台的 Agent 执行（读取本机 Unity 日志）。

设备清单（ADB）

枚举 Agent 机器上通过 ADB 连接的 Android 设备：型号 / 系统版本 / 分辨率 / 电量，清单随结果落档。无参数，选 Android 平台提交即可。

游戏性能测试配置（帧率 / 卡顿 / 内存）

基于 adb dumpsys gfxinfo/meminfo（PerfDog 思路精简版）：可选拉起游戏 → 重置帧统计 → 采样窗口 → 输出平均帧率/卡顿率/帧耗时百分位/内存峰值。需 Android Agent。

网站检查配置

由编排服务内置执行，无需 Agent；循环模式下每次完成后自动排下一次（监控模式）。

接口测试配置

支持自定义方法/请求头/请求体与三重断言（状态码/关键词/延迟）；自签名 HTTPS 目标可勾选跳过校验。

接口流程配置（多步骤链）

前序步骤可用 save 从响应 JSON 提取变量（点路径，如 data.token），后续步骤用 {{变量名}} 引用；任一步失败即停止。支持「失败/成功」重试与循环监控。

性能冒烟配置

轻量压测（k6 思路简化版）：全部请求状态码正确且 p95 达标才算通过；失败请求会给出错误样本。

端口检查配置（TCP 连通性）

由编排服务内置执行；循环模式适合登录服/网关端口的长效监控，失败自动 webhook 告警（见部署指南）。

证书检查配置（TLS 到期监控）

读取对端证书的到期时间与签发者，剩余天数低于阈值即失败；适合官网/账号服证书到期监控。自签名证书也可检查。

DNS 检查配置（解析断言）

解析成功且（如填写）期望 IP 命中才算通过；用于域名劫持/切换检测。

AI 探索测试配置

需要 Agent 以 AIAgent 技能运行并配置 OPENAI_API_KEY；每步会截图交给视觉大模型决策。

Airtest 脚本配置

需要 Agent 以 Airtest 技能运行并安装 airtest（pip install -r requirements-airtest.txt）。

GPT 生成用例配置

编排服务会先调用 GPT 生成 C# 测试代码（需配置 OPENAI_API_KEY），再由具备 GPTTestGen 技能的 Agent 执行。
